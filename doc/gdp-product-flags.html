GDP Flag FLG Format

Versioned flag sidecar files written beside GDP gains NPZ products.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-flag: create versioned GDP flag sidecar files.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.

Product Formats

  • gains NPZ
  • flag FLG
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Standard Name

NAME_V<version>.flg, where NAME is the matching GDP gains NPZ basename without .npz. gdp-flag writes the next version by default; --out-fver VERSION chooses a specific output version.

Example: gdp-gains-gain-scan17_V1.flg. For bandpass: gdp-gains-bandpass-scan18-chan_800_3000_V1.flg.

Arrays

ArrayDescription
header_jsonJSON metadata with format, version, input table, mode, channel selection, flag_version, and flag-intent. CASA table-derived flags always record the intent string CASA FLAGS.
scanScan number for each saved flag sample.
antennaAntenna ID for each saved flag sample.
stokesStokes/polarization index.
channelOriginal channel index.
rowOriginal CASA gain/bandpass table row index.
timeCASA TIME value for the original table row.
flagBoolean flag value with the same sample ordering and length as the matching gains NPZ.

Read This Product In Python

from pathlib import Path
import json
import numpy as np

path = Path("rundir/data-product/gains/npz/gdp-gains-gain-scan17_V1.flg")
with np.load(path, allow_pickle=True) as z:
    header = json.loads(str(z["header_json"]))
    row = z["row"].astype(int)
    stokes = z["stokes"].astype(int)
    channel = z["channel"].astype(int)
    flag = z["flag"].astype(bool)

lookup = {(int(r), int(s), int(c)): bool(f) for r, s, c, f in zip(row, stokes, channel, flag)}
print(header["flag_version"], len(lookup), int(flag.sum()))

Reading this product gives sample-level flags keyed by original CASA row, Stokes, and channel. GDP uses this mapping when --use-flags is set for stats, KS, self-correlation, colormap, or plotting modes. If --flagver requests a version that is not present beside the gains NPZ, GDP prints an ERROR message and stops.

Flag Intent

The flag-intent header is a list of provenance strings describing why samples were flagged. Current intents include CASA FLAGS, MANUAL ANTENNA FLAGS: ..., MANUAL CHANNEL FLAGS: ..., and PREVIOUS GDP FLAGS: V....

In gdp-flag, the highest existing GDP flag version is carried into the new output by default when one exists. Use --use-flags VERSION to carry a specific version. With --new-flags, only the newly requested fmode flags are written.

Use gdp-flag --fmode remove-version VERSION to delete a selected flag sidecar. If the version is omitted, GDP removes the highest available version for the matching gains NPZ basename. Missing requested versions are reported as ERROR: messages in the terminal and task log before GDP exits.
