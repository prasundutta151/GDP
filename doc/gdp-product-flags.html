Versioned flag sidecar files written beside GDP gains NPZ products.

Standard Name

NAME_fV<version>.flg, where NAME is the matching GDP gains NPZ basename without .npz. gdp-flag writes the next version by default; --out-fver VERSION chooses a specific output version.

Example: gdp-gains-gain-scan17_fV1.flg. For bandpass: gdp-gains-bandpass-scan18-chan_800_3000_fV1.flg.

Arrays

ArrayDescription
header_jsonJSON metadata with format, version, input table, mode, channel selection, flag_version, threshold_alpha, threshold_percent, threshold_factor, and flag-intent. CASA table-derived flags always record the intent string CASA FLAGS.
scanScan number for each saved flag sample.
antennaAntenna ID for each saved flag sample.
stokesStokes/polarization index.
channelOriginal channel index.
rowOriginal CASA gain/bandpass table row index.
timeCASA TIME value for the original table row.
flagBoolean flag value with the same sample ordering and length as the matching gains NPZ.

Read This Product In Python

from pathlib import Path
import json
import numpy as np

path = Path("rundir/data-product/gains/npz/gdp-gains-gain-scan17_fV1.flg")
with np.load(path, allow_pickle=True) as z:
    header = json.loads(str(z["header_json"]))
    row = z["row"].astype(int)
    stokes = z["stokes"].astype(int)
    channel = z["channel"].astype(int)
    flag = z["flag"].astype(bool)

lookup = {(int(r), int(s), int(c)): bool(f) for r, s, c, f in zip(row, stokes, channel, flag)}
print(header["flag_version"], len(lookup), int(flag.sum()))

Reading this product gives sample-level flags keyed by original CASA row, Stokes, and channel. GDP uses this mapping when --use-flags is set for stats, KS, self-correlation, colormap, or plotting modes. If --flagver requests a version that is not present beside the gains NPZ, GDP prints an ERROR message and stops.

Flag Intent

The flag-intent header is a list of provenance strings describing why samples were flagged. Current intents include CASA FLAGS, MANUAL ANTENNA FLAGS: ..., MANUAL CHANNEL FLAGS: ..., ALL STD THRESHOLD FLAGS: ..., ANTENNA STD THRESHOLD FLAGS: ..., ANTENNA MEAN THRESHOLD FLAGS: ..., ANTENNA FLAG FRACTION THRESHOLD FLAGS: ..., and KS THRESHOLD FLAGS: ....

Manual antenna and channel intents may include a Stokes selector with TARGET:STOKES. For example, 1:0 flags only Stokes 0 for antenna 1, [11-14]:1 flags Stokes 1 for antennas 11 through 14, and a target without :STOKES flags all Stokes for that target.

ALL STD THRESHOLD FLAGS records the alpha multiplier and, for each Stokes, the Real-1 and Imag stds in percent, the one-expected-point radius R, and the number of newly flagged points. ANTENNA STD THRESHOLD FLAGS records the same information separately for each antenna and Stokes.

ANTENNA MEAN THRESHOLD FLAGS records the threshold value and, for each antenna/Stokes group, the global Real-1/Imag standard deviations, the antenna's Real-1/Imag mean, the antenna-mean modulus, the derived cutoff modulus, and whether that antenna/Stokes group was promoted to flagged.

ANTENNA FLAG FRACTION THRESHOLD FLAGS records the percent threshold and, for each antenna, how much of the carried flag table was already flagged before promotion to a fully flagged antenna.

KS THRESHOLD FLAGS records the factor multiplier and, for each antenna/Stokes/component, the observed KS statistic, the mean KS from 128 same-size Gaussian-pair simulations, the threshold, and whether the group was promoted to flagged.

In gdp-flag, the highest existing GDP flag version is carried into the new output by default when one exists. Use --use-flags VERSION to carry a specific version. With --new-flags, only the newly requested fmode flags are written. When previous GDP flags are carried, the new output version keeps the existing flag-intent entries and appends the new flagging provenance so the history stays accumulated in the sidecar header.

Use gdp-flag --fmode remove-version VERSION to delete selected flag sidecars. VERSION can be a single version such as 3, a closed range such as [1-3], or an open-ended range such as [1:]. If the version is omitted, GDP removes the highest available version for the matching gains NPZ basename. Missing requested versions are reported as ERROR: messages in the terminal and task log before GDP exits.

Use gdp-flag --fmode summary [VERSION] to inspect an existing flag sidecar without writing a new one. GDP prints the stored flag-intent list and the per-antenna flagged-points summary for the requested version, or for the highest available version when VERSION is omitted.

Use gdp-flag --apply-flag [VERSION] to copy the original CASA gain or bandpass table and write a chosen GDP flag version into the copied table’s FLAG column. By default GDP writes the copied table under rundir/gaintable/ as <original>_fV<version>. The applied flag provenance is also written into CASA table keywords and README/comment lines when the available CASA table interface supports those metadata methods.
