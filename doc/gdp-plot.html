gdp-plot

Plot GDP NPZ products, creating missing products with gdp-stats when needed.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.

Product Formats

  • gains NPZ
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Purpose

gdp-plot reads the NPZ products created by gdp-stats and saves diagnostic plots under the configured runtime plot directory. If a requested NPZ product is missing, it first runs gdp-stats with the matching --smode task and then plots the newly created file. For the gain/bandpass colormap only, gdp-stats --smode colormap can also create the plot directly while producing the gains NPZ.

Usage

script/gdp-plot --mode gain -pmode stats  [plot stats from the gains NPZ, creating the gains NPZ first if missing]
script/gdp-plot --mode gain -pmode stats --adjust-mean  [divide real samples by the all-antenna mean and subtract the imaginary all-antenna mean for each stokes; output filename includes adjust-mean]
script/gdp-plot --mode gain -pmode stats --combine-scans  [plot one combined allscans stats view from the allscans gains product]
script/gdp-plot --mode gain -pmode colormap --range 20  [plot gain Real-1/Imag percent colormaps saturated at +/-20 percent]
script/gdp-plot --mode gain -pmode colormap --npz-path /path/to/gdp-gains-gain-scan2.npz  [plot directly from a selected gains NPZ]
script/gdp-plot --mode bandpass -pmode colormap --bchan 0 --echan 128  [plot bandpass Real-1/Imag percent colormaps by channel]
script/gdp-plot --mode bandpass -pmode colormap --bchan 0 --echan 128 -pchans "[16,64]" --range 20  [display channels 16 through 63 and saturate the colormap at +/-20 percent]
script/gdp-plot --mode bandpass -pmode stats --use-flags --flag-chans "[0,3000]"  [when creating a missing NPZ, pass the shorter-FLAG channel coverage to gdp-stats]
script/gdp-plot --mode gain -pmode hist --hist-bins 64  [plot AntStat-style per-antenna Real-1/Imag histograms from gains NPZ]
script/gdp-plot --mode gain -pmode reim --antenna 2,3  [plot pooled Real-1 versus Imag scatter and log10-count density panels for antennas 2 and 3]
script/gdp-plot --mode gain -pmode antenna 0,1,2  [make one AntStat-style gain-time plot per antenna, with Stokes side by side]
script/gdp-plot --mode gain --antenna [0,9] -pmode stats  [plot selected antenna range 0 through 9]
script/gdp-plot --mode gain --antenna 2,3,4,31 -pmode antenna  [plot only antennas 2, 3, 4, and 31]
script/gdp-plot --mode gain -pmode self-corr-antenna --antenna 0,1,2  [make per-antenna self-correlation plots]
script/gdp-plot --mode gain -pmode all  [make colormap, hist, stats, and KS plots only]
script/gdp-plot --mode both -pmode colormap,hist,stats,ks  [make selected plot modes for gain and bandpass]
script/gdp-plot -pmode cross-corr-colormap --antenna 0,1,2  [plot selected antennas from cross-corr NPZ]

Options

OptionDescription
--mode {gain,bandpass,both}Select which mode to plot. both runs each selected plot task for gain and bandpass.
-pmode MODE[,MODE...]Select plot products. Supported modes are all, colormap, hist, reim, antenna, stats, ks, self-corr-colormap, self-corr-antenna, and cross-corr-colormap. Legacy gain-colormap and gain-hist are accepted as aliases.
allExpand to only colormap, hist, stats, and ks. It does not run antenna, reim, self-correlation, or cross-correlation plot modes.
colormapPlot AntStat-style Real-1 and Imag percent colormaps from gdp-gains-<mode>-<scan>[-chan_<bchan>_<echan>].npz. Gain-mode plots use elapsed seconds from the saved time and interval arrays, show time-row numbers on the right-side axis of the right column, suppress duplicate left-side time labels there, include Delta t in the title, and use a 4:3 figure aspect ratio. Bandpass plots show nu in whole MHz on the left axis of left-column panels, preserve channel order from bottom upward, show channel numbers on the right axis of right-column panels, no duplicate left-axis labels on right-column panels, and show Delta nu in kHz with two decimal places in the title. Subplot mean/std/skew/kurtosis values are shown to one decimal place. The colorbar is symmetric from negative to positive saturation range and shows seven integer labels at multiples of 5 including 0.
histPlot AntStat-style per-antenna histograms from the full gains NPZ samples. Panels use the same Stokes/Real-1/Imag labels and compact summary-statistic titles as the colormap plots, with mean/std/skew/kurtosis shown to one decimal place. The y-axis is gain value percent with horizontal grid lines, right-column panels suppress duplicate y-axis levels, and the dedicated right colorbar uses two-decimal percent levels starting at 0.25 and increasing by factors of two up to the highest level available for the plotted scan and antenna selection.
reimPool all selected antennas into one plot, with Real-1 on the horizontal axis and Imag on the vertical axis for all finite unflagged points. If no antenna selection is supplied, all antennas in the NPZ are used. Columns are Stokes values. The top row shows individual samples with dashed vertical and horizontal mean lines. The bottom row shows 2D log10-count density as a colormap with log10-count contour overlays and point-count colorbar labels and the same mean reference lines. The colormap starts from the lowest displayed colorbar count (5), while the labels remain seven log-spaced count values starting at 5. All four panels include a dashed red linewidth-2 Gaussian expectation ellipse centered on the means; for the plotted sample count, only about one point is expected outside this ellipse for a matching 2D Gaussian. Each Stokes title reports pooled Real-1 and Imag mean/std/skew/kurtosis to one decimal place.
antennaMake one AntStat-style plot per selected antenna, with Stokes side by side and Real-1/Imag stacked. Gain mode plots versus elapsed seconds and adds a top time-row axis on the upper panels. Bandpass mode plots against channel positions, adds top channel-number axes on the upper panels, and labels the bottom axes of the lower panels as nu in whole MHz with endpoint ticks included. The full figure title is split across two rows with a smaller adaptive font and includes the table name, antenna, scan, gain-mode Delta t, and bandpass-mode Delta nu in kHz with two decimal places. Bandpass antenna plots use a tighter top layout to reduce blank space below the title. Each subplot uses a top-right legend such as Stokes 0 or Stokes 1 instead of a subplot title. All panels share a symmetric vertical range; right-column panels suppress duplicate left-axis labels, and the figure uses a 4:3 aspect ratio. Antennas may be supplied directly after the mode, for example -pmode antenna 3,5, or with --antenna.
statsPlot AntStat-style 2x2 per-antenna statistics grids from the full gains NPZ samples: mean, std, skewness, and kurtosis. The mean subplot title is Mean [%]; real traces are labeled with re-1 because the plotted real mean is shown as real minus 1, while imaginary mean is plotted without the minus-1 offset. Mean, skewness, and kurtosis panels include a black dashed zero reference line. The plot title follows the colormap title style with table name and scan. The figure uses a 4:3 aspect ratio.
ksPlot AntStat-style per-antenna KS D-statistic lines from the KS NPZ product. Each Stokes/real-imag data series is accompanied by a same-color horizontal dashed reference line from the mean of 128 two-sample KS comparisons between simulated Gaussian pairs using a representative median sample count for that series. The legend is placed inside the lower part of the plot in four columns and two rows, with measured series on the top row and simulated dashed references on the bottom row. The y-axis range includes both the highest measured KS value and the highest simulated reference line. The figure title follows the same table/scan format used by the colormap and stats plots, and the figure uses a 4:3 aspect ratio with tight plot margins.
self-corr-colormapPlot AntStat-style structure-function colormaps with Stokes rows, Real-1/Imag columns, antenna on x, tau on y, and log10(S2) color. Positive log colorbar levels start at 0.25 and increase by factors of two up to the highest available level in the plotted scan and antenna selection.
self-corr-antennaPlot AntStat-style per-antenna structure-function curves with S2=1 and threshold reference lines.
cross-corr-colormapPlot antenna-pair tcorr colormaps from the cross-correlation NPZ product.
--combine-scansPlot one combined allscans-style product. Default: false, so GDP makes one plot per scan.
--adjust-meanFor -pmode stats, compute shared all-antenna means for each stokes and component. Real samples are divided by the shared real mean; imaginary samples subtract the shared imaginary mean. Default: false. When enabled, the output filename includes adjust-mean.
--hist-bins INTNumber of gain-value bins for -pmode hist. Default: 64.
--hist-range MIN,MAXOptional gain-value range in percent for -pmode hist. Default: symmetric range covering the plotted extrema.
--antenna LISTAntenna selection. Use --antenna [0,9] for an inclusive range. Use --antenna 2,3,4,31 or --antenna 2 3 4 31 for explicit antenna numbers. The same list is passed to gdp-stats if missing products must be created.
--scan LISTUse the matching scan-specific product name, and pass the scan list to gdp-stats if products are missing.
--input-table PATHExplicit input table passed to gdp-stats when an NPZ product must be created.
--gain-table PATH, --bandpass-table PATHMode-specific tables passed to gdp-stats when missing gain or bandpass NPZ products must be created.
--setup-file NAMESetup JSON file to use for product directories and for any missing-product gdp-stats calls.
--npz-path PATHUse the given NPZ file directly for the selected -pmode instead of discovering a default product or creating a missing product with gdp-stats. The NPZ must match the selected plot mode, for example a gains NPZ for colormap, hist, reim, antenna, or stats.
--bchan INT, --echan INTBandpass channel selection passed to gdp-stats when needed. When both are supplied in bandpass mode, GDP looks for and writes default filenames with -chan_<bchan>_<echan>.
-pchans [START,END]Plot-only channel window for gains-based plot modes: colormap, hist, reim, antenna, and stats. The start channel is inclusive and the end channel is exclusive. Existing or newly created NPZ products still use --bchan/--echan; -pchans only limits displayed channels and any subplot-title statistics calculated during plotting. Default plot filenames append pchan_<start>_<end>.
--range FLOATColormap saturation half-range in percent for gain or bandpass -pmode colormap. For example, --range 20 uses -20 to +20 percent. Values are rounded up to a multiple of 5, with seven colorbar labels that include 0 and use no decimal places.
--flag-chans [START,END]Pass-through to gdp-stats when gdp-plot creates a missing NPZ with --use-flags. It declares which original data channels a shorter FLAG channel axis covers; all other channels are treated as flagged.
--use-flagsPass --use-flags to gdp-stats when missing products must be created. Default: disabled, so missing products are created without flag masking unless this option is set.
--s2-thr FLOATThreshold used for self-correlation reference lines and colormap markers. Default: 0.9.
--plot-dir PATHOutput plot directory. Default: configured plots/<format> runtime directory.
--format {png,pdf,eps}Plot file format. Default: png. PNG files are written at 320 dpi.
--recomputeRun gdp-stats before plotting even when the NPZ file already exists.
--dry-runPrint the gdp-stats commands that would create missing products.

Default Plot Names

Plots are saved as gdp-plot-<task>-<mode>-<scan>.<format>. By default the scan field is per scan, such as scan1. With --combine-scans, the scan field is allscans when no scan list is supplied. In bandpass mode, when both --bchan and --echan are supplied, plot names append -chan_<bchan>_<echan>, for example gdp-plot-colormap-bandpass-scan2-chan_0_128.png. If -pchans is supplied for a gains-based plot, plot names also append -pchan_<start>_<end>. The antenna mode writes one file per antenna with -ant<antenna>. The reim mode writes one pooled file with -allants or -ants<list>.
