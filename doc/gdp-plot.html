gdp-plot

Plot GDP NPZ products, creating missing products with gdp-stats when needed.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.

Product Formats

  • gains NPZ
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Purpose

gdp-plot reads the NPZ products created by gdp-stats and saves diagnostic plots under the configured runtime plot directory. If a requested NPZ product is missing, it first runs gdp-stats with the matching --smode task and then plots the newly created file. For the gain/bandpass colormap only, gdp-stats --smode gain-colormap can also create the plot directly while producing the gains NPZ.

Usage

script/gdp-plot --mode gain -pmode stats  [plot stats from the gains NPZ, creating the gains NPZ first if missing]
script/gdp-plot --mode gain -pmode stats --adjust-mean  [divide real samples by the all-antenna mean and subtract the imaginary all-antenna mean for each stokes; output filename includes adjust-mean]
script/gdp-plot --mode gain -pmode stats --combine-scans  [plot one combined allscans stats view from the allscans gains product]
script/gdp-plot --mode bandpass -pmode gain-colormap --bchan 0 --echan 128  [plot bandpass Real-1/Imag percent colormaps by channel]
script/gdp-plot --mode gain -pmode gain-hist --hist-bins 64  [plot AntStat-style per-antenna Real-1/Imag histograms from gains NPZ]
script/gdp-plot --mode gain -pmode antenna 0,1,2  [make one AntStat-style gain-time plot per antenna, with Stokes side by side]
script/gdp-plot --mode gain --antenna "(0,9)" -pmode stats  [plot selected antenna range 0 through 9]
script/gdp-plot --mode gain --antenna 1 2 3 4 13 -pmode antenna  [plot only antennas 1, 2, 3, 4, and 13]
script/gdp-plot --mode gain -pmode self-corr-antenna --antenna 0,1,2  [make per-antenna self-correlation plots]
script/gdp-plot --mode both -pmode gain-colormap,gain-hist,stats,ks  [make selected plot modes for gain and bandpass]
script/gdp-plot -pmode cross-corr-colormap --antenna 0,1,2  [plot selected antennas from cross-corr NPZ]

Options

OptionDescription
--mode {gain,bandpass,both}Select which mode to plot. both runs each selected plot task for gain and bandpass.
-pmode MODE[,MODE...]Select plot products. Supported modes are gain-colormap, gain-hist, antenna, stats, ks, self-corr-colormap, self-corr-antenna, and cross-corr-colormap.
gain-colormapPlot AntStat-style Real-1 and Imag percent colormaps from gdp-gains-<mode>-<scan>.npz. Gain-mode plots use elapsed seconds from the saved time and interval arrays, show time-row numbers on the right-side axis of the right column, suppress duplicate left-side time labels there, include Delta t in the title, and use a 4:3 figure aspect ratio. The percent colorbar shows one-decimal tick labels on the left side. Bandpass plots use channel.
gain-histPlot AntStat-style per-antenna histograms from the full gains NPZ samples. Panels use the same Stokes/Real-1/Imag labels and compact summary-statistic titles as the colormap plots, y-axis is gain value percent with horizontal grid lines, right-column panels suppress duplicate y-axis levels, and the dedicated right colorbar uses two-decimal percent levels starting at 0.25 and increasing by factors of two up to the highest level available for the plotted scan and antenna selection.
antennaMake one AntStat-style plot per selected antenna, with Stokes side by side and Real-1/Imag stacked. Gain mode plots versus elapsed seconds and adds a top time-row axis on the upper panels; bandpass mode plots versus channel. Each subplot uses a top-right legend such as Stokes 0 or Stokes 1 instead of a subplot title. The full figure title includes the table name, antenna, scan, percent units, and gain-mode Delta t. All panels share a symmetric vertical range; right-column panels suppress duplicate left-axis labels, and the figure uses a 4:3 aspect ratio. Antennas may be supplied directly after the mode, for example -pmode antenna 3,5, or with --antenna.
statsPlot AntStat-style 2x2 per-antenna statistics grids from the full gains NPZ samples: mean, std, skewness, and kurtosis. The mean subplot title is Mean [%]; real traces are labeled with re-1 because the plotted real mean is shown as real minus 1, while imaginary mean is plotted without the minus-1 offset. Mean, skewness, and kurtosis panels include a black dashed zero reference line. The plot title follows the colormap title style with table name, scan, and percent units. The figure uses a 4:3 aspect ratio.
ksPlot AntStat-style per-antenna KS D-statistic lines from the KS NPZ product. Each Stokes/real-imag data series is accompanied by a same-color horizontal dashed reference line from the mean of 128 two-sample KS comparisons between simulated Gaussian pairs using a representative median sample count for that series. The legend is placed inside the lower part of the plot in four columns and two rows, with measured series on the top row and simulated dashed references on the bottom row. The y-axis range includes both the highest measured KS value and the highest simulated reference line. The figure title follows the same table/scan/percent format used by the colormap and stats plots, and the figure uses a 4:3 aspect ratio with tight plot margins.
self-corr-colormapPlot AntStat-style structure-function colormaps with Stokes rows, Real-1/Imag columns, antenna on x, tau on y, and log10(S2) color. Positive log colorbar levels start at 0.25 and increase by factors of two up to the highest available level in the plotted scan and antenna selection.
self-corr-antennaPlot AntStat-style per-antenna structure-function curves with S2=1 and threshold reference lines.
cross-corr-colormapPlot antenna-pair tcorr colormaps from the cross-correlation NPZ product.
--combine-scansPlot one combined allscans-style product. Default: false, so GDP makes one plot per scan.
--adjust-meanFor -pmode stats, compute shared all-antenna means for each stokes and component. Real samples are divided by the shared real mean; imaginary samples subtract the shared imaginary mean. Default: false. When enabled, the output filename includes adjust-mean.
--hist-bins INTNumber of gain-value bins for --gain-hist. Default: 64.
--hist-range MIN,MAXOptional gain-value range in percent for --gain-hist. Default: symmetric range covering the plotted extrema.
--antenna LISTAntenna selection. Use --antenna "(0,9)" or --antenna "[0,9]" for an inclusive range. Use --antenna 1,2,3,4,13 or --antenna 1 2 3 4 13 for explicit antenna numbers. The same list is passed to gdp-stats if missing products must be created.
--scan LISTUse the matching scan-specific product name, and pass the scan list to gdp-stats if products are missing.
--input-table PATHExplicit input table passed to gdp-stats when an NPZ product must be created.
--gain-table PATH, --bandpass-table PATHMode-specific tables passed to gdp-stats when missing gain or bandpass NPZ products must be created.
--setup-file NAMESetup JSON file to use for product directories and for any missing-product gdp-stats calls.
--bchan INT, --echan INTBandpass channel selection passed to gdp-stats when needed.
--use-flagsPass --use-flags to gdp-stats when missing products must be created. Default: disabled, so missing products are created without flag masking unless this option is set.
--s2-thr FLOATThreshold used for self-correlation reference lines and colormap markers. Default: 0.9.
--plot-dir PATHOutput plot directory. Default: configured plots/<format> runtime directory.
--format {png,pdf,eps}Plot file format. Default: png. PNG files are written at 320 dpi.
--recomputeRun gdp-stats before plotting even when the NPZ file already exists.
--dry-runPrint the gdp-stats commands that would create missing products.

Default Plot Names

Plots are saved as gdp-plot-<task>-<mode>-<scan>.<format>. By default the scan field is per scan, such as scan1. With --combine-scans, the scan field is allscans when no scan list is supplied.
