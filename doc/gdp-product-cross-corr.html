GDP Cross-Correlation NPZ Format

Planned cross structure-function correlation-time products reserved by gdp-stats --smode cross-corr.

Product Formats

  • gains NPZ
  • flag FLG
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Step-by-Step Guide

For the recommended workflow from setup through data products, flag versions, plots, plans, and release steps, see the GDP step-by-step guide.

Standard Name

gdp-cross-corr-<mode>-<scan>.npz

Example: gdp-cross-corr-gain-scan1.npz. With --combine-scans: gdp-cross-corr-gain-allscans.npz.

Output Location

By default this product is written under rundir/data-product/cross-corr/npz/, or under the configured runtime directory from gdp-setup.

Arrays

ArrayDescription
header_jsonJSON metadata with product name, mode, scan selection, column order, and correlation settings.
scanScan number for the antenna-pair measurement.
ant1First antenna ID in the baseline-like antenna pair.
ant2Second antenna ID in the antenna pair.
stokesStokes/polarization index used for the comparison.
componentsGain components used in the comparison, such as real-real, real-imag, imag-real, or imag-imag.
thresholdStructure-function threshold used to extract the correlation time. Default: 0.7.
tcorrEstimated cross-correlation time from the first valid lag bin crossing the threshold. Written as nan when no valid crossing is found.
nbin_validNumber of lag bins with finite structure-function values.
npairTotal sample-pair count contributing to the antenna-pair estimate.

Optional CSV

Use --csv or --output-cross-corr-csv PATH to also write gdp-cross-corr-<mode>-<scan>.csv. The CSV columns match the NPZ arrays except for header_json.

Related Options

OptionUse
--output-cross-corr-npz PATHWrite the default NPZ product to a specific path.
--output-cross-corr-csv PATHAlso write the optional CSV product to a specific path.
--corr-threshold FLOATSet the threshold used for tcorr.
--corr-nbin INTSet the lag-bin count.
--corr-bintype {log,lin}Choose logarithmic or linear lag bins.

Read This Product In Python

from pathlib import Path
import json
import numpy as np

path = Path("rundir/data-product/cross-corr/npz/gdp-cross-corr-gain-scan2.npz")
with np.load(path, allow_pickle=True) as z:
    header = json.loads(str(z["header_json"]))
    scan = z["scan"].astype(int)
    ant1 = z["ant1"].astype(int)
    ant2 = z["ant2"].astype(int)
    stokes = z["stokes"].astype(str)
    components = z["components"].astype(str)
    threshold = z["threshold"].astype(float)
    tcorr = z["tcorr"].astype(float)
    nbin_valid = z["nbin_valid"].astype(int)
    npair = z["npair"].astype(int)

finite = np.isfinite(tcorr)
print("finite tcorr rows:", np.count_nonzero(finite))
print("first finite tcorr:", tcorr[finite][0] if np.any(finite) else "none")

Reading this product gives one row per antenna pair, Stokes pairing, and component pairing. Use tcorr as the extracted correlation time, threshold as the S2 crossing level used, and nbin_valid/npair to judge whether the estimate is well supported.
