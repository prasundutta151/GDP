GDP Documentation

GDP (Gain Diagnostic Product) is a command-line toolkit for gain and bandpass diagnostics, data products, plotting, diagnosis, and flag products.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-flag: create versioned GDP flag sidecar files.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.
  • Step-by-step guide: run GDP from setup through products, flags, plots, plans, and release steps.

Product Formats

  • gains NPZ
  • flag FLG
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Runtime Layout

The default repository runtime directory is rundir/. A user may choose a different runtime directory with gdp-setup.

Quick Start

script/gdp-setup --gain-table /path/to/gain/table.g --bandpass-table /path/to/bandpass/table.b --rundir /path/to/rundir  [save separate gain and bandpass defaults plus runtime directory]
script/gdp-setup --setup-file project-a-setup.json --gain-table /path/to/table.g --rundir /path/to/rundir  [write a named setup file under the runtime directory]
script/gdp-setup --show  [print the saved GDP setup]
script/gdp-util --input-table /path/to/table.g --header  [inspect table metadata]
script/gdp-util --gain-table --header  [inspect the saved gain table]
script/gdp-util --bandpass-table --header  [inspect the saved bandpass table]
script/gdp-stats --smode stats,ks  [compute stats and KS products from the saved input]
script/gdp-stats --smode all  [run gains, stats, KS, and self-corr]
script/gdp-stats --antennas [0,9] --smode stats  [compute stats for antennas 0 through 9]
script/gdp-stats --antennas 2,3,4,31 --smode stats  [compute stats for explicit antenna IDs]
script/gdp-stats --antennas "(1,5)" 6 "(9-12)" 15 16 19 --smode stats  [compute stats for mixed antenna ranges and explicit IDs]
script/gdp-stats --smode stats --csv  [compute stats and optional CSV from the saved input]
script/gdp-stats --smode stats --combine-scans  [write one combined allscans stats product]
script/gdp-stats --mode gain --scan 17 --smode gains  [create the gains NPZ for plotting]
script/gdp-plot --mode gain --scan 17 -pmode colormap --range 20  [plot gain Real-1/Imag colormaps with fixed percent saturation]
script/gdp-stats --mode gain --scan 17 --smode gains --flagver 1  [write gains NPZ and matching V1 flag sidecar]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna 3,4 --use-flags  [create the next flag version by carrying the highest old version and adding antennas 3 and 4]
script/gdp-flag --mode bandpass --scan 18 --bchan 800 --echan 3000 --fmode man-chann --man-chann "[900,1200]" --new-flags  [write only new manual channel flags]
script/gdp-stats --mode gain --scan 17 --smode stats,ks --use-flags --flagver 1  [compute flagged products using V1 .flg flags]
script/gdp-plot --mode gain --scan 17 -pmode colormap --npz-path /path/to/gdp-gains-gain-scan17.npz  [plot directly from a selected gain scan-17 NPZ file]
script/gdp-plot --mode bandpass --scan 18 --bchan 800 --echan 3000 -pmode colormap -pchans "[800,1200]" --range 20  [plot a channel window from a wider bandpass scan-18 gains NPZ with fixed percent saturation]
script/gdp-plot --mode gain -pmode hist  [plot AntStat-style gain histograms from gains NPZ]
script/gdp-plot --mode gain --scan 17 -pmode antenna --antenna "[0,29]"  [plot antennas 0 through 29 with Stokes side by side]
script/gdp-plot --mode gain -pmode stats  [plot stats from the gains NPZ, creating the gains NPZ first if needed]
script/gdp-plot --mode gain -pmode all  [plot colormap, hist, stats, and KS only]
script/gdp-plan-run pipelines/sample_stats.plan --dry-run  [preview a pipeline plan without running it]
