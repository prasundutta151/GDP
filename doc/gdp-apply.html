gdp-apply

Copy a CASA calibration table and write selected GDP samples and flags into it.

Usage

script/gdp-apply --mode gain --scan 17 --datacolumn casa --output-casa-table /path/to/output.g
script/gdp-apply --mode bandpass --scan 18 --datacolumn model --antenna "[0-29]" --chans 800 3000 --use-flags --output-casa-table /path/to/output.b

Behavior

--output-casa-table is required. GDP copies the input CASA table, replaces selected samples in its calibration data column with casa (default) or model gains NPZ samples, then writes a selected sidecar into CASA FLAG. If the output already exists, GDP asks before replacing it; use --force for non-interactive overwrite. If the requested model is absent, GDP keeps original CASA samples and can still apply a valid sidecar. If neither model samples nor flags are available, GDP prints errors and creates no output table. If a requested/highest flag sidecar is absent, GDP prints an error and writes available data without applying flags.
