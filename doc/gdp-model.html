gdp-model

Fit gain and bandpass models into the model column of a saved GDP gains NPZ.

Workflow

script/gdp-stats --mode gain --scan 17 --smode gains
script/gdp-model --mode gain --scan 17 --mmode gdp matern32
script/gdp-stats --mode gain --scan 17 --smode stats --datacolumn model
script/gdp-plot --mode gain --scan 17 --pmode colormap --datacolumn model

The command preserves casa_real/casa_imag and adds model_real/model_imag. Existing real/imag arrays remain CASA-compatible aliases.

Model Modes

--mmode polynomial [1-16], harmonic [1-16], poly-harmonic [1-16], gauss-hermite [3-16], or default gdp [rbf|matern32|exp]. GDP mode combines short and long local kernel smooths; default kernel is matern32.

--scan, --antenna, --stokes, and --complex select series. --use-flags --flagversion VERSION excludes sidecar-flagged samples. --output-gains-npz writes a copy; --dry-run, --estimate, --parallel, and --output-csv are supported.
