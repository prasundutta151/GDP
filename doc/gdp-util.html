Purpose

gdp-util provides small metadata utilities behind one command. It can print table headers, observing dates, scan lists, antenna lists, channel summaries, channel-width, band-width, integration-time summaries, and the saved GDP setup configuration. It also updates the GDP version file and provides --git-push for the GDP release/git workflow.

Usage

script/gdp-util --input-table /path/to/table.g --header  [show table rows, columns, IDs, and data-column descriptions]
script/gdp-util --mode gain --header  [show header metadata from the saved gain table]
script/gdp-util --mode bandpass --header --date  [show header and date metadata from the saved bandpass table]
script/gdp-util --input-table /path/to/other.g --mode gain --header --json  [show metadata from an explicit gain table path]
script/gdp-util --input-table /path/to/table.g --header --keywords --json  [write header and keyword metadata as JSON]
script/gdp-util --input-table /path/to/table.g --date  [show observing date and time span]
script/gdp-util --mode gain --scans --antenna  [show scans and antennas in the saved gain table]
script/gdp-util --mode gain --timeinfo  [show NTime, delta-T, and start/end times in IST and GMT]
script/gdp-util --mode bandpass --chaninfo  [show bandpass bandwidth, channel width, channel count, and frequency range]
script/gdp-util --mode bandpass --channelwidth  [show channel width in kHz or MHz from the saved bandpass table]
script/gdp-util --mode bandpass --bandwidth  [show bandwidth in kHz or MHz from the saved bandpass table]
script/gdp-util --mode gain --integration-time  [show integration-time_sec from median TIME spacing in the saved gain table]
script/gdp-util --config  [print the saved GDP setup configuration]
script/gdp-util --version  [bump the lower/patch version number]
script/gdp-util --version main  [bump the main/major version number and reset lower numbers]
script/gdp-util --version 1.2.0  [set VERSION to an exact version number]
script/gdp-util --version --git-push -m "Release update"  [bump VERSION, build archive, commit, and push]
script/gdp-util --git-push -m "Describe the change"  [build the version archive, commit, and push]

Options

OptionDescription
--input-table PATHExplicit CASA table or MeasurementSet path.
--mode {gain,bandpass}Saved setup table to use when --input-table is omitted. Default: gain. Channel actions require --mode bandpass; time actions require --mode gain. If the wrong mode is used, GDP prints an ERROR: message and exits before reading the table.
--headerPrint row count, columns, common IDs, data columns, and column descriptions.
--keywordsInclude CASA table keywords in header output.
--datePrint IST observing dates and time span from the TIME column.
--scansPrint the scan numbers present in the selected table.
--antennaPrint the antenna numbers present in the selected table.
--chaninfoBandpass mode only. Print bandpass channel information: mean channel width, mean total bandwidth, number of channels, and start/end frequency, using kHz or MHz keys as appropriate.
--timeinfoGain mode only. Print NTime, median delta-T_sec, and start/end times in IST and GMT from the gain-table TIME column.
--channel-width, --channelwidthPrint only the mean channel width from the bandpass table as chan-width_kHz or chan-width_MHz. If no explicit table is supplied, GDP uses the saved bandpass_table.
--band-width, --bandwidthPrint only the mean total bandwidth from the bandpass table as band-width_kHz or band-width_MHz. If no explicit table is supplied, GDP uses the saved bandpass_table.
--integration-timePrint only integration-time_sec, calculated as the median positive spacing between unique gain-table TIME values in one scan. If no explicit table is supplied, GDP uses the saved gain_table.
--configPrint the saved GDP setup configuration.
--version [NUMBER|main]Update VERSION. Bare --version bumps the patch/lower number, --version main bumps the major/main number, and --version NUMBER sets an exact version. If used with --git-push, the version update happens first and the archive/commit uses the new version.
--git-pushCreate gdp-<VERSION>.tgz, stage GDP source/docs/notes/archive files, commit, and push the current branch.
-m, --message TEXTCommit message for --git-push. Defaults to GDP update <version>.
--no-pushWith --git-push, create the archive and commit without pushing.
--relative-pathFor human-readable output, print the runtime directory near startup, then show saved runtime file references relative to that directory. JSON output remains machine-readable and unchanged.
--jsonWrite machine-readable JSON output.

Git Workflow

The --git-push mode builds a versioned archive from the GDP tree, excluding local runtime products, git internals, cache files, and local setup state. It stages project files such as DEV_NOTES.md, DEV_PLAN.md, REQUIREMENTS.md, doc/, script/, and the version archive before committing and pushing.
