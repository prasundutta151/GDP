Purpose

gdp-util provides small metadata utilities behind one command. It can print table headers, observing dates, channel-width summaries, and the saved GDP setup configuration. It also updates the GDP version file and provides --git-push for the GDP release/git workflow.

Usage

script/gdp-util --input-table /path/to/table.g --header  [show table rows, columns, IDs, and data-column descriptions]
script/gdp-util --gain-table --header  [show header metadata from the saved gain table]
script/gdp-util --bandpass-table --header --date  [show header and date metadata from the saved bandpass table]
script/gdp-util --gain-table /path/to/other.g --header --json  [show metadata from an explicit gain table path]
script/gdp-util --input-table /path/to/table.g --header --keywords --json  [write header and keyword metadata as JSON]
script/gdp-util --input-table /path/to/table.g --date  [show observing date and time span]
script/gdp-util --input-table /path/to/table.ms --channel-width  [show channel-width statistics in MHz]
script/gdp-util --config  [print the saved GDP setup configuration]
script/gdp-util --version  [bump the lower/patch version number]
script/gdp-util --version main  [bump the main/major version number and reset lower numbers]
script/gdp-util --version 1.2.0  [set VERSION to an exact version number]
script/gdp-util --version --git-push -m "Release update"  [bump VERSION, build archive, commit, and push]
script/gdp-util --git-push -m "Describe the change"  [build the version archive, commit, and push]

Options

OptionDescription
--input-table PATHExplicit CASA table or MeasurementSet path.
--gain-table [PATH]Use a gain table for --header, --date, or --channel-width. Without PATH, use the saved gain_table from gdp-setup.
--bandpass-table [PATH]Use a bandpass table for --header, --date, or --channel-width. Without PATH, use the saved bandpass_table from gdp-setup.
--headerPrint row count, columns, common IDs, data columns, and column descriptions.
--keywordsInclude CASA table keywords in header output.
--datePrint IST observing dates and time span from the TIME column.
--channel-widthPrint channel-width statistics in MHz.
--configPrint the saved GDP setup configuration.
--version [NUMBER|main]Update VERSION. Bare --version bumps the patch/lower number, --version main bumps the major/main number, and --version NUMBER sets an exact version. If used with --git-push, the version update happens first and the archive/commit uses the new version.
--git-pushCreate gdp-<VERSION>.tgz, stage GDP source/docs/notes/archive files, commit, and push the current branch.
-m, --message TEXTCommit message for --git-push. Defaults to GDP update <version>.
--no-pushWith --git-push, create the archive and commit without pushing.
--jsonWrite machine-readable JSON output.

Git Workflow

The --git-push mode builds a versioned archive from the GDP tree, excluding local runtime products, git internals, cache files, and local setup state. It stages project files such as DEV_NOTES.md, DEV_PLAN.md, REQUIREMENTS.md, doc/, script/, and the version archive before committing and pushing.
