gdp-show

Open existing GDP PNG plots in a filterable browser gallery.

Purpose

gdp-show never recalculates a product or regenerates a plot. It finds matching PNG files in plots/png, writes plots/png/gdp-show.html, and opens that gallery in the system browser. Missing requested plot types are reported as NOT AVAILABLE while available plots continue to be shown.

Usage

script/gdp-show                              [show all existing gain and bandpass plots]
script/gdp-show --mode gain                  [show all existing gain plots]
script/gdp-show --mode bandpass --flagver 5  [show bandpass plots made with fV5]
script/gdp-show --mode gain --stats          [show colormap, stats, and KS plots]
script/gdp-show --self-corr                  [show self-corr antenna and colormap plots]
script/gdp-show --cross-corr                 [show cross-corr antenna and grid plots]

Options

OptionDescription
--mode gain|bandpassRestrict to one data mode. Omit it to include both modes.
--flagver N [N ...]Restrict to one or more GDP flag versions. Omit it to include unflagged and all flagged plot files.
--statsShow only colormap, statistics, and KS plots.
--self-corrShow only self-correlation antenna and colormap plots.
--cross-corrShow only cross-correlation antenna and grid plots.
--setup-file NAMEUse a named setup JSON file under the configured runtime directory.

Multiple selective options combine their matching plot families. If no selective option is supplied, all available plot families are included.
