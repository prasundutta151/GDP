gdp-flag

Create versioned GDP flag sidecar files for gain and bandpass products.

Purpose

gdp-flag creates NAME_fV<version>.flg sidecar files beside the matching GDP gains NPZ. It can write flags from the original CASA gain/bandpass table, add manual antenna or channel flags, create threshold flags from the Real-1 versus Imag gain plane, and apply a chosen GDP flag version back into a copied CASA table under the runtime gaintable/ folder.

Usage

script/gdp-flag --mode gain --scan 17 --fmode casa-flags  [write CASA table flags to the next flag version]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna 3,4  [carry the highest old flag version by default and add antennas 3 and 4]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna 3,4 --new-flags  [write only the new manual antenna flags]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna "1:0, 3:1, [11-14]:1, 23"  [flag selected Stokes for antennas 1, 3, 11 through 14, and all Stokes for antenna 23]
script/gdp-flag --mode bandpass --scan 18 --fmode man-chan --man-chan "[900-1200]" --use-flags 2  [carry fV2 and flag channels 900 through 1200]
script/gdp-flag --mode bandpass --scan 18 --fmode man-chan --man-chan "[900-1200]:1, 1300:0"  [flag Stokes 1 for channels 900 through 1200 and Stokes 0 for channel 1300]
script/gdp-flag --mode gain --scan 17 --fmode all-std-thrsld  [flag points outside the one-expected-point RE/IM ellipse with alpha=1]
script/gdp-flag --mode gain --scan 17 --fmode all-std-thrsld 1.5  [use alpha=1.5 times the one-expected-point radius]
script/gdp-flag --mode gain --scan 17 --fmode ante-std-thrsld  [calculate the RE/IM ellipse per antenna and Stokes]
script/gdp-flag --mode gain --scan 17 --fmode ante-std-thrsld --alpha 1.5  [per-antenna thresholding with alpha=1.5]
script/gdp-flag --mode gain --scan 17 --fmode ante-mean-thrsld  [flag antennas whose antenna-mean Real-1 or Imag is outside the one-expected-antenna Gaussian cutoff]
script/gdp-flag --mode gain --scan 17 --fmode ante-mean-thrsld 1.5  [use threshold=1.5 times the Gaussian antenna-mean cutoff]
script/gdp-flag --mode gain --scan 17 --fmode ante-thrsld  [flag any full antenna with at least 70 percent existing flags]
script/gdp-flag --mode gain --scan 17 --fmode ante-thrsld 40  [flag any full antenna with at least 40 percent existing flags]
script/gdp-flag --mode gain --scan 17 --fmode ante-thrsld --percent 40  [same threshold using the explicit percent option]
script/gdp-flag --mode gain --scan 17 --fmode ks-thrsld  [flag antenna/Stokes groups whose Real or Imag KS exceeds 1 times the Gaussian reference]
script/gdp-flag --mode gain --scan 17 --fmode ks-thrsld 1.5  [use 1.5 times the Gaussian reference]
script/gdp-flag --mode gain --scan 17 --fmode ks-thrsld --factor 1.5  [same multiplier using the explicit factor option]
script/gdp-flag --mode bandpass --scan 18 --fmode all-std-thrsld --alpha 2  [threshold the full bandpass product with alpha=2]
script/gdp-flag --mode gain --scan 17 --fmode remove-version 3  [remove flag version fV3 for the matching gain product]
script/gdp-flag --mode gain --scan 17 --fmode remove-version "[1-3]"  [remove flag versions fV1 through fV3 for the matching gain product]
script/gdp-flag --mode gain --scan 17 --fmode remove-version "[1:]"  [remove all matching flag versions starting at fV1]
script/gdp-flag --mode gain --scan 17 --fmode remove-version  [remove the highest flag version for the matching gain product]
script/gdp-flag --mode gain --scan 17 --fmode summary  [show the per-antenna summary for the highest matching flag version]
script/gdp-flag --mode gain --scan 17 --fmode summary 3  [show the per-antenna summary for flag version fV3]
script/gdp-flag --mode gain --scan 17 --apply-flag  [copy the saved gain table into rundir/gaintable and write the highest matching flag version into its CASA FLAG column]
script/gdp-flag --mode gain --scan 17 --apply-flag 3 --output-table /path/to/output/table_fV3.g  [apply flag version fV3 into a chosen output CASA table path]
script/gdp-flag --setup-file project-a-setup.json --mode bandpass --scan 18 --fmode casa-flags  [use a named setup file from the active runtime directory]

Options

OptionDescription
--input-table PATHExplicit CASA gain/bandpass table path.
--gain-table PATHNamed gain table path. Defaults to saved gain_table in gain mode.
--bandpass-table PATHNamed bandpass table path. Defaults to saved bandpass_table in bandpass mode.
--setup-file NAMESetup JSON file to use. Relative names are resolved under the active runtime directory.
--relative-pathPrint the runtime directory near startup, then show generated runtime file references relative to that directory in terminal and log messages. Actual output filenames and write locations are unchanged.
--mode {auto,gain,bandpass}Flagging mode. Default: auto.
--scan LISTComma-separated scans. Default: all scans.
--combine-scansCombine selected scans into one allscans-style flag product.
--antennas LIST, --antenna LISTAntenna selection used to define the output flag product dimensions. Mixed ranges and explicit lists follow the same syntax as gdp-stats --antennas.
--bchan INTStart channel, inclusive. Bandpass mode only.
--echan INTEnd channel, exclusive. Bandpass mode only.
--use-flags [VERSION]Choose an existing GDP .flg file to carry into the output. If the version is omitted, GDP uses the highest available version beside the matching gains NPZ. If this option is omitted entirely, GDP still carries the highest previous version when one exists.
--new-flagsWrite only the new flags from the selected --fmode; do not carry any previous GDP flag version.
--out-fver VERSIONOutput flag version. Default: next version beside the matching gains NPZ.
--apply-flag [VERSION]Standalone action that copies the selected input CASA table and writes the requested GDP flag version into its CASA FLAG column. If VERSION is omitted, GDP uses the highest available matching version.
--output-table PATHOutput CASA table path used with --apply-flag. If omitted, GDP writes under rundir/gaintable/ (or the configured runtime gaintable_dir) as <original>_fV<version>.
--fmode casa-flagsWrite flags already present in the CASA gain or bandpass table. The flag-intent header records CASA FLAGS.
--fmode man-antennaFlag manually selected antennas. Supply values with --man-antenna LIST or as trailing values after the mode. Add :STOKES to flag only selected Stokes; omit :STOKES to flag all Stokes. Examples: 1:0, [1-4]:1, (1, 3):0, and 1:0, 3:1, [11-14]:1, 23.
--fmode man-chanFlag manually selected bandpass channels. Supply values with --man-chan LIST or as trailing values after the mode. Add :STOKES to flag only selected Stokes; omit :STOKES to flag all Stokes. Examples: 900:0, [900-1200]:1, (900, 1300):0, and [900-1200] for the existing square-bracket inclusive range form. If used with --mode gain, GDP prints an ERROR: message and exits before reading table rows.
--fmode all-std-thrsld [ALPHA]Compute Real-1 and Imag standard deviations from all selected antennas together for each Stokes separately, using percent units. For each Stokes, GDP forms a zero-centered normalized RE/IM distance and flags samples whose distance is greater than ALPHA * R, where R = sqrt(2 ln N). If ALPHA is omitted, GDP uses 1. The equivalent explicit option is --alpha VALUE.
--fmode ante-std-thrsld [ALPHA]Use the same zero-centered Real-1/Imag threshold rule as all-std-thrsld, but calculate the standard deviations and R for each antenna and Stokes independently. A sample is flagged only against the threshold derived from its own antenna and Stokes group.
--fmode ante-mean-thrsld [THRESHOLD]For each Stokes, GDP computes each antenna’s mean Real-1 and mean Imag over all selected unflagged finite samples: over time in gain mode and over channels in bandpass mode. It then computes the mean and standard deviation of those antenna means. With N valid antennas, GDP calculates a two-sided Gaussian cutoff gamma where only one antenna is expected outside ±gamma sigma. Antennas with Real-1 or Imag mean offsets greater than THRESHOLD * gamma * std_of_antenna_means are fully flagged for that Stokes. If fewer than eight valid antennas are available, GDP logs an insufficient-antenna message and skips that Stokes. If THRESHOLD is omitted, GDP uses 1. The equivalent explicit option is --alpha VALUE.
--fmode ante-thrsld [PERCENT]Inspect the existing flag table for each antenna. In bandpass mode, GDP counts unflagged (Stokes, channel) units for every antenna and uses the maximum such count across antennas as the reference size. In gain mode, it does the same with unflagged (Stokes, time) units. If at least PERCENT percent of that reference availability is missing for an antenna, GDP flags the entire antenna in the output flag version. If PERCENT is omitted, GDP uses 70. The equivalent explicit option is --percent VALUE.
--fmode ks-thrsld [FACTOR]For each antenna and Stokes, calculate fitted-normal KS statistics for Real-1 and Imag samples. For the same sample size, GDP generates 128 Gaussian-pair realizations, averages their KS values, and flags the antenna/Stokes group if either Real or Imag has KS greater than FACTOR times that Gaussian mean. If FACTOR is omitted, GDP uses 1. The equivalent explicit option is --factor VALUE.
--fmode remove-version [VERSION]Remove matching .flg sidecar versions. Use a single version like 3, a closed range like [1-3], or an open-ended range like [1:]. If VERSION is omitted, GDP removes the highest available version for the selected mode, scan, and channel naming base.
--fmode summary [VERSION]Read a matching .flg sidecar version and print its stored flag-intent provenance plus the per-antenna flag summary to the terminal and task log. If VERSION is omitted, GDP uses the highest available version for the selected mode, scan, and channel naming base.
auto-ante, auto-chanReserved placeholders for later automatic flagging algorithms.
--alpha VALUEThreshold multiplier for --fmode all-std-thrsld, --fmode ante-std-thrsld, or --fmode ante-mean-thrsld. Default: 1.
--percent VALUEFlagged-data percentage threshold for --fmode ante-thrsld. Default: 70.
--factor VALUEKS threshold multiplier for --fmode ks-thrsld. Default: 1.
--output-gains-npz PATHMatching gains NPZ path used as the filename base for the .flg file.
--write-gains-npzRewrite the matching gains NPZ even if it already exists.

After each completed flagging cycle, gdp-flag writes the accumulated flag-intent provenance and a per-antenna summary table to the terminal and task log. The active flagging summary uses compact columns: fmod-per for the percentage flagged by the current --fmode, pts as final flagged points over total points, and fin_per for the final accumulated flagged percentage. With --apply-flag, GDP copies the CASA table first, writes the selected version into the copied table’s FLAG column, and stores the flag provenance in table keywords and README/comment lines when the CASA table interface supports them. If a required flag version is requested but not present, gdp-flag writes an ERROR: line to the terminal and the task log, then exits without a Python traceback.
