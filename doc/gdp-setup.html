gdp-setup

Initialize and remember the GDP runtime environment.

Purpose

gdp-setup creates the runtime directory structure and saves separate gain and bandpass table locations so later GDP commands can reuse the correct default for each mode. It stores a setup JSON file inside the runtime directory, initializes a gaintable/ folder for CASA table copies, and updates the active GDP configuration used by the other commands.

Usage

script/gdp-setup --gain-table /path/to/gain/table.g --bandpass-table /path/to/bandpass/table.b --rundir /path/to/work/rundir  [save separate gain and bandpass defaults plus runtime directory]
script/gdp-setup --gain-table /path/to/gain/table.g --rundir /path/to/work/rundir  [save only the gain table and runtime directory]
script/gdp-setup --bandpass-table /path/to/bandpass/table.b --rundir /path/to/work/rundir  [save only the bandpass table and runtime directory]
script/gdp-setup --setup-file project-a-setup.json --gain-table /path/to/table.g --rundir /path/to/work/rundir  [write a named setup file under the runtime directory]
script/gdp-setup --show  [print the saved GDP setup]

Options

OptionDescription
--rundir PATHRuntime directory to create or use. Defaults to the saved value, then <GDP>/rundir.
--gain-table PATHGain calibration table remembered as the default for gain-mode GDP commands.
--bandpass-table PATHBandpass calibration table remembered as the default for bandpass-mode GDP commands.
--setup-file NAMESetup JSON file name to store inside the runtime directory. If omitted, GDP writes gdp-setup.json. Before overwriting that default file, the previous copy is archived with a .YYYYMMDDTHHMMSS suffix.
--config PATHActive configuration JSON path used by GDP commands. Defaults to <GDP>/.gdp-config.json.
--showPrint the saved configuration and exit.
--dry-runShow the directories and configuration that would be written.
--allow-missing-tableAllow gain or bandpass table paths to be recorded before they exist.

The runtime directory includes data-product/, logs/, plots/, and gaintable/. gdp-flag --apply-flag writes copied CASA gain or bandpass tables under gaintable/ unless --output-table is supplied.
