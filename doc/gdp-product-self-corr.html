Normalized structure-function curves saved by gdp-stats --smode self-corr.

Standard Name

gdp-self-corr-<mode>-<scan>[_fV<version>].npz

Example: gdp-self-corr-gain-scan1.npz. With --combine-scans: gdp-self-corr-gain-allscans.npz. Channel and antenna selections are stored in the product metadata/arrays but are not added to the default filename.

Arrays

ArrayDescription
header_jsonJSON metadata with correlation settings such as lag binning, bin count, jackknife folds, S2 crossing threshold, flag policy, GDP .flg flag version metadata.
scanScan number for each lag-bin row.
antennaAntenna ID for each lag-bin row.
stokesStokes/polarization index.
componentComponent label: real or imag.
tauLag-bin center.
s2Normalized order-2 structure-function value.
errJackknife uncertainty when requested.
countPair count contributing to the lag bin.
corr_*One row per scan/antenna/Stokes/component with the fitted threshold crossing. Arrays include corr_scan, corr_antenna, corr_stokes, corr_component, corr_lag, corr_lag_err, corr_tcorr_sec/corr_tcorr_sec_err for gain mode, and corr_dnucorr_hz/corr_dnucorr_hz_err plus corr_dnucorr_mhz/corr_dnucorr_mhz_err for bandpass mode.

The normalized S2 curve is smoothed in log-lag space before the threshold crossing is estimated. Jackknife errors are saved in err, and crossing uncertainties are estimated by perturbing finite S2 bins by their jackknife errors. Plot labels enforce a display minimum uncertainty of two channel widths for nu_corr and two integration times for tau_corr; the saved arrays keep the fitted estimates.

For bandpass plots, corr_lag is the channel separation at the threshold crossing. gdp-plot -pmode self-corr-all-ante also displays that crossing in channel units with both the value and uncertainty rounded upward to integer channel counts.

If all samples for an antenna/stokes/component are flagged or non-finite, GDP keeps the expected lag-bin rows with s2 and err set to NaN and count set to zero. Plotting code renders those bins as blank or white cells.

Read This Product In Python

from pathlib import Path
import json
import numpy as np

path = Path("rundir/data-product/self-corr/npz/gdp-self-corr-gain-scan2.npz")
with np.load(path, allow_pickle=True) as z:
    header = json.loads(str(z["header_json"]))
    scan = z["scan"].astype(int)
    antenna = z["antenna"].astype(int)
    stokes = z["stokes"].astype(int)
    component = z["component"].astype(str)
    tau = z["tau"].astype(float)
    s2 = z["s2"].astype(float)
    err = z["err"].astype(float)
    count = z["count"].astype(int)

mask = (antenna == 0) & (stokes == 0) & (component == "real")
print("antenna 0 real tau:", tau[mask])
print("antenna 0 real S2:", s2[mask])

Reading this product gives a long table of structure-function lag bins. Each row belongs to one scan, antenna, Stokes, component, and lag tau. Use s2 for the normalized structure-function value, err for jackknife uncertainty, and count to see how many pairs contributed to the bin.
