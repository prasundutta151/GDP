GDP Documentation

GDP (Gain Diagnostic Product) is a command-line toolkit for gain and bandpass diagnostics, data products, plotting, diagnosis, and flag products.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-flag: create versioned GDP flag sidecar files.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-show: browse existing GDP plots without recalculating products.
  • gdp-plan-run: run GDP command intents from a plan file.
  • Step-by-step guide: run GDP from setup through products, flags, plots, plans, and release steps.

Product Formats

  • gains NPZ
  • flag FLG
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Runtime Layout

The default repository runtime directory is rundir/. A user may choose a different runtime directory with gdp-setup. script/gdp-setup --clean removes generated outputs under data-product/, plots/, logs/, and gaintable/, then recreates the standard runtime folders. It asks for confirmation by default; use --clean --dry-run to preview the delete list or --clean no-stop for scripted cleanup without the prompt. Setup JSON files in the runtime root and .gdp-config.json are kept.

Add --relative-path to GDP commands when terminal/log output should first state the runtime directory and then refer to generated runtime files relative to that directory. This is a display-only option: actual filenames, write locations, and machine-readable JSON output are unchanged.

Quick Start

script/gdp-setup --gain-table /path/to/gain/table.g --bandpass-table /path/to/bandpass/table.b --rundir /path/to/rundir  [save separate gain and bandpass defaults plus runtime directory]
script/gdp-setup --setup-file project-a-setup.json --gain-table /path/to/table.g --rundir /path/to/rundir  [write a named setup file under the runtime directory]
script/gdp-setup --show  [print the saved GDP setup]
script/gdp-setup --clean --dry-run  [preview generated runtime outputs that would be removed]
script/gdp-setup --clean  [ask for confirmation, then remove generated runtime outputs]
script/gdp-setup --clean no-stop  [remove generated runtime outputs without prompting]
script/gdp-util --input-table /path/to/table.g --header  [inspect table metadata]
script/gdp-util --mode gain --header  [inspect the saved gain table]
script/gdp-util --mode bandpass --header  [inspect the saved bandpass table]
script/gdp-util --mode gain --scans --antenna  [inspect scans and antennas]
script/gdp-util --mode gain --timeinfo  [inspect gain-table time count, spacing, and start/end times]
script/gdp-util --mode bandpass --chaninfo  [inspect bandpass channel width, bandwidth, channel count, and frequency range]
script/gdp-stats --smode stats,ks  [compute stats and KS products from the saved input]
script/gdp-stats --smode all  [run gains, stats, and KS]
script/gdp-stats --smode self-corr  [run self-correlation separately]
script/gdp-stats --mode gain --scan 17 --smode gains,cross-corr --stokes 01 --complex reim  [write gains, then selected cross-corr NPZ products]
script/gdp-stats --mode gain --scan 17 --smode cross-corr --estimate --parallel  [estimate cross-corr runtime/disk from the saved gains NPZ]
script/gdp-plot --mode gain --scan 17 -pmode cross-corr-antenna --ant-pair 0 1 --stokes-pair 01 --cmplx-pair reim  [plot one selected cross-corr curve]
script/gdp-plot --mode bandpass --scan 18 -pmode cross-corr-grid --use-flags --clip  [plot cross-corr nu_corr antenna-pair grids with the automatic 32 Delta-nu upper scale]
script/gdp-stats --antennas [0-9] --smode stats  [compute stats for antennas 0 through 9]
script/gdp-stats --antennas 2,3,4,31 --smode stats  [compute stats for explicit antenna IDs]
script/gdp-stats --antennas "[1-5]" 6 "[9-12]" 15 16 19 --smode stats  [compute stats for mixed antenna ranges and explicit IDs]
script/gdp-stats --smode stats --csv  [compute stats and optional CSV from the saved input]
script/gdp-stats --smode stats --combine-scans  [write one combined allscans stats product]
script/gdp-stats --mode gain --scan 17 --smode gains  [create the gains NPZ for plotting]
script/gdp-stats --mode gain --scan 17 --smode gain --adjust-mean  [create a mean-adjusted gains NPZ]
script/gdp-plot --mode gain --scan 17 -pmode colormap --range 20  [plot gain Real-1/Imag colormaps with fixed percent saturation]
script/gdp-stats --mode gain --scan 17 --smode gains --flagver 1  [write gains NPZ and matching fV1 flag sidecar]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna 3,4 --use-flags  [create the next flag version by carrying the highest old version and adding antennas 3 and 4]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna "1:0, 3:1, [11-14]:1, 23"  [flag selected Stokes for some antennas and all Stokes for antenna 23]
script/gdp-flag --mode bandpass --scan 18 --fmode man-chan --man-chan "[900-1200]" --new-flags  [write only new manual channel flags]
script/gdp-flag --mode bandpass --scan 18 --fmode man-chan --man-chan "[900-1200]:1, 1300:0"  [flag selected Stokes for selected bandpass channels]
script/gdp-flag --mode gain --scan 17 --fmode all-std-thrsld  [flag RE/IM outliers using alpha=1]
script/gdp-flag --mode gain --scan 17 --fmode all-std-thrsld 1.5  [flag RE/IM outliers using alpha=1.5]
script/gdp-flag --mode gain --scan 17 --fmode ante-std-thrsld  [flag RE/IM outliers using per-antenna statistics]
script/gdp-flag --mode gain --scan 17 --fmode ante-std-thrsld --alpha 1.5  [per-antenna thresholding with alpha=1.5]
script/gdp-flag --mode gain --scan 17 --fmode ante-mean-thrsld  [flag antenna/Stokes means outside the one-expected-antenna Gaussian cutoff]
script/gdp-flag --mode gain --scan 17 --fmode ante-mean-thrsld 1.5  [use threshold=1.5 times the Gaussian antenna-mean cutoff]
script/gdp-flag --mode gain --scan 17 --fmode ante-thrsld  [fully flag antennas with at least 70 percent existing flags]
script/gdp-flag --mode gain --scan 17 --fmode ante-thrsld 40  [fully flag antennas with at least 40 percent existing flags]
script/gdp-flag --mode gain --scan 17 --fmode ks-thrsld  [flag antenna/Stokes groups whose KS exceeds 1 times the Gaussian reference]
script/gdp-flag --mode gain --scan 17 --fmode ks-thrsld 1.5  [flag antenna/Stokes groups whose KS exceeds 1.5 times the Gaussian reference]
script/gdp-flag --mode gain --scan 17 --fmode gpr  [flag non-smooth gain time samples with default multi-scale GPR settings]
script/gdp-flag --mode bandpass --scan 18 --fmode gpr --thrsld 5 --kernel matern32 --scale 16,128  [flag non-smooth bandpass channel samples]
script/gdp-flag --mode bandpass --scan 18 --fmode all-std-thrsld --alpha 2  [threshold the full bandpass product using alpha=2]
script/gdp-flag --mode gain --scan 17 --fmode remove-version "[1-3]"  [remove flag versions fV1 through fV3]
script/gdp-flag --mode gain --scan 17 --fmode remove-version "[1:]"  [remove all matching flag versions starting at fV1]
script/gdp-flag --mode gain --scan 17 --fmode summary  [show the per-antenna summary for the highest matching flag version]
script/gdp-flag --mode gain --scan 17 --fmode summary 3  [show the per-antenna summary for flag version fV3]
script/gdp-flag --mode gain --scan 17 --apply-flag  [copy the saved gain table to rundir/gaintable and apply the highest matching flag version]
script/gdp-flag --mode gain --scan 17 --apply-flag 3 --output-table /path/to/output/table_fV3.g  [apply fV3 to a chosen output CASA table path]
script/gdp-stats --mode gain --scan 17 --smode stats,ks --use-flags --flagver 1  [compute flagged products using fV1 .flg flags; default names include _fV1]
script/gdp-plot --mode gain --scan 17 -pmode colormap --use-flags --flagver 1  [plot using fV1 flags; default name includes _fV1]
script/gdp-plot --mode gain --scan 13 -pmode colormap --npz-path /path/to/gdp-gains-gain-scan13.npz  [plot directly from a selected gain scan-13 NPZ file]
script/gdp-plot --mode bandpass --scan 18 -pmode colormap -pchans "[800-1200]" --range 20  [plot a channel window from a wider bandpass scan-18 gains NPZ with fixed percent saturation]
script/gdp-plot --mode gain -pmode hist  [plot AntStat-style gain histograms from gains NPZ]
script/gdp-plot --mode gain --scan 17 -pmode antenna --antenna "[0-29]"  [plot antennas 0 through 29 with Stokes side by side]
script/gdp-plot --mode gain -pmode stats  [plot stats from the gains NPZ, creating the gains NPZ first if needed]
script/gdp-plot --mode gain -pmode all  [plot colormap, hist, stats, and KS only]
script/gdp-show --mode gain  [open all existing gain plots in a browser gallery]
script/gdp-show --mode bandpass --flagver 5 --self-corr  [open available fV5 bandpass self-correlation plots]
script/gdp-plan-run pipelines/sample_stats.plan --dry-run  [preview a pipeline plan without running it]
