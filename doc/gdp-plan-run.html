gdp-plan-run

Run repeatable GDP workflows from simple plan files.

Purpose

gdp-plan-run reads a plan file, expands internal variables, and runs GDP command intents such as gdp-stats, gdp-flag, and gdp-plot. It is the first pipeline runner for repeatable GDP workflows.

Usage

script/gdp-plan-run pipelines/sample_stats.plan  [run every intent in the plan]
script/gdp-plan-run pipelines/sample_stats.plan --dry-run  [print commands without executing them]
script/gdp-plan-run pipelines/sample_stats.plan --setup-file project-a-setup.json  [run the plan with a named setup file]
script/gdp-plan-run pipelines/sample_stats.plan --only gdp-stats  [run only intents whose command is gdp-stats]

Options

OptionDescription
plan_fileRequired GDP plan file path.
--setup-file NAMESetup JSON file to use for plan variables and for gdp-stats, gdp-flag, and gdp-plot intents. Relative names are resolved under the active runtime directory.
--dry-runPrint commands without running them.
--only VALUERun only the matching intent index, command name, or intent name.

Plan Format

A plan can optionally set setup-file: NAME at the top, then define variables and one or more intent blocks. Values may reference variables with ${name}. Saved gdp-setup paths, such as ${gain_table}, ${bandpass_table}, ${stats_npz_dir}, and ${stats_csv_dir}, are available when configured.

setup-file: project-a-setup.json

variables:
  stats_npz: ${stats_npz_dir}/sample_gain_stats.npz

intent: gdp-stats
  name: gain statistics
  mode: gain
  combine-scans: true
  smode: stats
  output-npz: ${stats_npz}
  csv: true
end

intent: gdp-plot
  name: plot gain statistics
  mode: gain
  combine-scans: true
  pmode: stats
end

Intent keys become CLI flags. For example, output-npz becomes --output-npz. Boolean true values become standalone flags, while false and null values are omitted. For gdp-stats, task selection should be written as smode: stats,ks rather than older boolean task keys.

Options that accept multiple command-line tokens can be written as shell-style values in the plan. This includes antenna lists, plot channel windows, manual flag selections, and gdp-flag --fmode trailing values. Quote bracketed ranges when they should remain one token.

intent: gdp-flag
  mode: gain
  scan: 19
  fmode: man-antenna 9
end

intent: gdp-flag
  mode: gain
  scan: 19
  fmode: man-antenna
  man-antenna: "[1-5]" 6 "[9-12]" 15
end

intent: gdp-flag
  mode: bandpass
  scan: 18
  fmode: man-chan
  man-chan: "[900-1200]:1" 1300:0
end

intent: gdp-flag
  mode: gain
  scan: 19
  fmode: ks-thrsld 1.5
end
