GDP Gains NPZ Format

Raw selected gain/bandpass samples saved by gdp-stats --smode gains.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.

Product Formats

  • gains NPZ
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Standard Name

gdp-gains-<mode>-<scan>[-chan_<bchan>_<echan>].npz

Example: gdp-gains-gain-scan1.npz. With --combine-scans: gdp-gains-gain-allscans.npz. In bandpass mode with --bchan 0 --echan 128: gdp-gains-bandpass-scan1-chan_0_128.npz.

Arrays

ArrayDescription
header_jsonJSON metadata with format, version, input table, mode, data column, flag policy, shorter-FLAG channel coverage from --flag-chans, forced antenna flags from --antenna-flag, channel selection, and column names.
scanScan number for each saved sample.
antennaAntenna ID for each saved sample.
stokesStokes/polarization index.
channelChannel index after selection.
rowOriginal CASA table row index.
timeCASA TIME value for the original table row, in seconds.
intervalCASA INTERVAL value for the original table row, in seconds. Used to scale gain colormap time bins.
channel_freq_hzChannel frequency from the table SPECTRAL_WINDOW subtable when available, otherwise NaN.
channel_width_hzChannel width from the table SPECTRAL_WINDOW subtable when available, otherwise NaN.
realReal component value; flagged samples become NaN when flags are used.
imagImaginary component value; flagged samples become NaN when flags are used.
flaggedBoolean flag state for each sample.

Read This Product In Python

from pathlib import Path
import json
import numpy as np

path = Path("rundir/data-product/gains/npz/gdp-gains-gain-scan2.npz")
with np.load(path, allow_pickle=True) as z:
    header = json.loads(str(z["header_json"]))
    scan = z["scan"].astype(int)
    antenna = z["antenna"].astype(int)
    stokes = z["stokes"].astype(int)
    channel = z["channel"].astype(int)
    time = z["time"].astype(float)
    interval = z["interval"].astype(float)
    real = z["real"].astype(float)
    imag = z["imag"].astype(float)
    flagged = z["flagged"].astype(bool)

print(header["mode"], np.unique(antenna), real.shape)

Reading this product gives one long table of gain or bandpass samples. Each row is identified by scan, antenna, Stokes, channel, original CASA row, and time. Use real, imag, and flagged to build antenna plots, colormaps, and histograms. If --antenna-flag was used, the forced antennas are listed in header["antenna_flags"] and their samples are saved as flagged/non-finite.
