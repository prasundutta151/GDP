gdp-stats

Compute antenna-wise gain and bandpass statistics products.

Purpose

gdp-stats reads a CASA gain or bandpass table and creates GDP data products. If no input table is supplied, gain mode uses the saved gain_table and bandpass mode uses the saved bandpass_table from gdp-setup. Each requested subtask writes to the runtime product folders and records timing information in a log file.

Usage

script/gdp-setup --gain-table /path/to/table.g --bandpass-table /path/to/table.b --rundir /path/to/rundir  [save separate gain and bandpass defaults plus runtime directory]
script/gdp-stats --smode stats,ks  [compute statistics and KS products from the saved input]
script/gdp-stats --smode all  [run gains, stats, and KS]
script/gdp-stats --smode cross-corr  [record the cross-corr placeholder task]
script/gdp-stats --setup-file project-a-setup.json --smode stats  [use a named setup file from the active runtime directory]
script/gdp-stats --smode stats --csv  [compute statistics from the saved input and also write CSV]
script/gdp-stats --mode gain --scan 17 --smode gains  [create the gains NPZ for plotting]
script/gdp-plot --mode gain --scan 17 -pmode colormap --range 20  [save Real-1/Imag percent colormap plots saturated at +/-20 percent]
script/gdp-plot --mode bandpass -pmode colormap -pchans "[16-64]" --range 20  [plot only channels 16 through 64, saturating the colormap at +/-20 percent]
script/gdp-stats --mode gain --scan 17 --smode gains --flagver 1  [write gains NPZ and matching gdp-gains-gain-scan17_fV1.flg]
script/gdp-stats --mode gain --scan 17 --smode stats,ks --use-flags --flagver 1  [compute flagged stats and KS from the fV1 .flg sidecar]
script/gdp-flag --mode gain --scan 17 --fmode man-antenna --man-antenna 3,4 --use-flags  [create a new flag version by carrying the highest old version and adding antennas 3 and 4]
script/gdp-stats --smode stats --combine-scans  [combine scans into one allscans stats product]
script/gdp-stats --input-table /path/to/table.b --mode bandpass --smode gains,stats  [process the bandpass table and save gains plus stats]
script/gdp-stats --scan 1,2 --antennas 0,1,2 --smode all  [run gains, stats, and KS for selected antennas]
script/gdp-stats --antennas [0-9] --smode stats  [use antennas 0 through 9 inclusively]
script/gdp-stats --antennas 1 2 3 4 13 --smode stats  [use only antennas 1, 2, 3, 4, and 13]
script/gdp-stats --antennas "[1-5]" 6 "[9-12]" 15 16 19 --smode stats  [use mixed antenna ranges and single antennas]

Options

OptionDescription
--input-table PATHExplicit CASA gain/bandpass table path.
--gain-table PATHNamed gain table path. Defaults to saved gain_table in gain mode.
--bandpass-table PATHNamed bandpass table path. Defaults to saved bandpass_table in bandpass mode.
--setup-file NAMESetup JSON file to use. Relative names are resolved under the active runtime directory. If omitted, GDP uses the setup file last activated by gdp-setup.
--relative-pathPrint the runtime directory near startup, then show generated runtime file references relative to that directory in terminal and log messages. Actual output filenames and write locations are unchanged.
--mode {auto,gain,bandpass}Statistics mode. Default: auto.
--scan LISTComma-separated scans. Default: all scans.
--combine-scansCombine selected scans into one allscans-style product. Default: false, so GDP writes one product per scan.
--antennas LISTAntenna selection. Use --antennas [0-9] for an inclusive range. Use --antennas 2,3,4,31 or --antennas 2 3 4 31 for explicit antenna numbers. Mixed selections are allowed, for example --antennas "[1-5]" 6 "[9-12]" 15 16 19. Default: all antennas.
--use-flagsFor --smode gains, save the CASA table FLAG state into a versioned .flg sidecar. For stats, ks, and self-corr, apply flags from the matching .flg sidecar. Manual flag creation is handled by gdp-flag.
--flagver VERSIONFlag sidecar version. With --smode gains, write NAME_fV<VERSION>.flg; if omitted, GDP writes the next version. With --use-flags consumers, use that version; if omitted, GDP uses the highest available version and reports it in the log. Default flagged data-product names append _fV<version>. If the requested version does not exist, GDP prints an ERROR message and stops.
--smode MODE[,MODE...]Select stats products. Supported modes are gain, gains, stats, ks, self-corr, all, and cross-corr. Modes may be comma or space separated.
gainsSave selected gain/bandpass samples as a GDP gains NPZ product and write a matching versioned .flg sidecar containing the CASA table flag state.
statsCompute AntStat-style per-antenna mean, std, skew, kurtosis, median, MAD, min, and max statistics. This remains the default when no subtask is selected.
ksCompute AntStat-style per-antenna fitted-normal KS D-statistics.
self-corrCompute self structure-function correlation curves, jackknife errors, and fitted threshold-crossing time/frequency estimates. Antenna/stokes/component series with fewer than two finite unflagged samples are skipped and saved as NaN lag bins.
allRun the standard stats modes: gains, stats, and ks. Use --smode self-corr explicitly for self-correlation products.
cross-corrReserved placeholder for cross-correlation products. GDP logs the task but does not write a cross-corr product yet.
--output-npz PATHOutput NPZ path. Default: configured stats/npz runtime directory.
--output-gains-npz PATHOutput gains NPZ path. Default: configured gains/npz runtime directory.
--output-ks-npz PATHOutput KS NPZ path. Default: configured ks/npz runtime directory.
--output-self-corr-npz PATHOutput self-correlation NPZ path. Default: configured self-corr/npz runtime directory.
--output-cross-corr-npz PATHOutput cross-correlation NPZ path. Default: configured cross-corr/npz runtime directory.
--output-cross-corr-csv PATHReserved for future cross-correlation CSV output.
--corr-threshold FLOATS2 threshold used for cross-correlation time extraction. Default: 0.7.
--corr-nbin INTStructure-function lag bin count. Default: 32.
--corr-bintype {log,lin}Structure-function lag binning. Default: log.
--corr-njack INTJackknife folds for structure-function errors. Default: 32.
--adjust-meanFor --smode gain, --smode gains, or --smode stats, adjust selected finite unflagged samples by the all-antenna mean per Stokes before writing the product. Real gain samples are divided by the real mean; imaginary samples subtract the imaginary mean.
--csvAlso write optional CSV products for selected subtasks that support CSV, including stats and cross-correlation.
--output-csv PATHWrite CSV to a specific path; implies --csv.

Subtasks and Logs

Before products are created, gdp-stats checks any requested --scan values against the selected gain or bandpass table. If a scan is absent, it prints a text error with the missing and available scans and stops. Each subtask prints a start/done message with elapsed time and writes the same messages to a timestamped log file under the configured logs runtime directory.

Standard Product Names

SubtaskDefault filenameFormat page
--smode gainsgdp-gains-<mode>-<scan>.npzgains NPZ
--smode gainsgdp-gains-<mode>-<scan>_fV<version>.flgflag FLG
--smode statsgdp-stats-<mode>-<scan>[_fV<version>].npzstats NPZ
--smode ksgdp-ks-<mode>-<scan>[_fV<version>].npzKS NPZ
--smode self-corrgdp-self-corr-<mode>-<scan>[_fV<version>].npzself-corr NPZ
--smode cross-corrplaceholder onlyplanned cross-corr NPZ
gdp-plot -pmode histgdp-plot-hist-<mode>-<scan>[-pchan_<start>_<end>].pngplot from gains NPZ

The <scan> field is scan1, scan2, etc. by default. With --combine-scans, the field is allscans when no scan list is supplied, or scan1-2/scan5 style when --scan is supplied. Default gdp-stats product names do not include channel selections or antenna selections. When --use-flags is applied to derived products, GDP appends _fV<version> before the extension, for example gdp-stats-gain-scan17_fV1.npz.
