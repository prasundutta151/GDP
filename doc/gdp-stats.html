gdp-stats

Compute antenna-wise gain and bandpass statistics products.

Documentation Tree

  • Main documentation
  • gdp-setup: initialize and remember runtime, gain-table, and bandpass-table locations.
  • gdp-util: read metadata from CASA gain, bandpass, or MeasurementSet tables.
  • gdp-stats: compute antenna-wise gain and bandpass products.
  • gdp-plot: plot GDP NPZ products and create missing products with gdp-stats.
  • gdp-plan-run: run GDP command intents from a plan file.

Product Formats

  • gains NPZ
  • stats NPZ
  • KS NPZ
  • self-corr NPZ
  • cross-corr NPZ

Purpose

gdp-stats reads a CASA gain or bandpass table and creates GDP data products. If no input table is supplied, gain mode uses the saved gain_table and bandpass mode uses the saved bandpass_table from gdp-setup. Each requested subtask writes to the runtime product folders and records timing information in a log file.

Usage

script/gdp-setup --gain-table /path/to/table.g --bandpass-table /path/to/table.b --rundir /path/to/rundir  [save separate gain and bandpass defaults plus runtime directory]
script/gdp-stats --smode stats,ks  [compute statistics and KS products from the saved input]
script/gdp-stats --smode all  [run gains, colormap, stats, KS, and self-corr]
script/gdp-stats --smode cross-corr  [record the cross-corr placeholder task]
script/gdp-stats --setup-file project-a-setup.json --smode stats  [use a named setup file from the active runtime directory]
script/gdp-stats --smode stats --csv  [compute statistics from the saved input and also write CSV]
script/gdp-stats --mode gain --smode colormap --range 20  [create gains NPZ and save Real-1/Imag percent colormap plots saturated at +/-20 percent]
script/gdp-stats --mode bandpass --smode colormap -pchans "[16,64]" --range 20  [plot only channels 16 through 63, saturating the colormap at +/-20 percent]
script/gdp-stats --mode bandpass --smode stats --use-flags --flag-chans "[0,3000]"  [use a shorter 3000-channel FLAG axis and treat all channels outside 0 through 2999 as flagged]
script/gdp-stats --smode stats --combine-scans  [combine scans into one allscans stats product]
script/gdp-stats /path/to/table.b --mode bandpass --bchan 0 --echan 128 --smode gains,stats  [process selected bandpass channels and save gains plus stats]
script/gdp-stats --scan 1,2 --antennas 0,1,2 --smode all  [run every implemented stats subtask for selected antennas]
script/gdp-stats --antennas [0,9] --smode stats  [use antennas 0 through 9 inclusively]
script/gdp-stats --antennas 1 2 3 4 13 --smode stats  [use only antennas 1, 2, 3, 4, and 13]
script/gdp-stats --antennas "(1,5)" 6 "(9-12)" 15 16 19 --smode stats  [use mixed antenna ranges and single antennas]
script/gdp-stats --smode all --antenna-flag 3,4  [force antennas 3 and 4 to be treated as flagged/non-finite while keeping them in product axes]

Options

OptionDescription
input_tableOptional positional CASA gain/bandpass table path.
--input-table PATHNamed input table path. Overrides the positional path.
--gain-table PATHNamed gain table path. Defaults to saved gain_table in gain mode.
--bandpass-table PATHNamed bandpass table path. Defaults to saved bandpass_table in bandpass mode.
--setup-file NAMESetup JSON file to use. Relative names are resolved under the active runtime directory. If omitted, GDP uses the setup file last activated by gdp-setup.
--mode {auto,gain,bandpass}Statistics mode. Default: auto.
--scan LISTComma-separated scans. Default: all scans.
--combine-scansCombine selected scans into one allscans-style product. Default: false, so GDP writes one product per scan.
--antennas LISTAntenna selection. Use --antennas [0,9] for an inclusive range. Use --antennas 2,3,4,31 or --antennas 2 3 4 31 for explicit antenna numbers. Mixed selections are allowed, for example --antennas "(1,5)" 6 "(9-12)" 15 16 19. Default: all antennas.
--antenna-flag LISTForce selected antennas to be treated as flagged. Uses the same list/range/mixed syntax as --antennas. Forced antennas remain in output axes, but their gains, stats, KS, and correlation samples are saved as flagged or non-finite.
--bchan INTStart channel, inclusive. In bandpass mode, when both --bchan and --echan are supplied, default product names include chan_<bchan>_<echan>.
--echan INTEnd channel, exclusive. In bandpass mode, when both --bchan and --echan are supplied, default product names include chan_<bchan>_<echan>.
-pchans [START,END]Plot-only channel window for --smode colormap. The start channel is inclusive and the end channel is exclusive. The gains NPZ is still created from the normal --bchan/--echan selection, but the colormap display and subplot-title mean/std/skew/kurtosis use only the selected plot channels. Default plot names append pchan_<start>_<end>.
--range FLOATColormap saturation half-range in percent for gain or bandpass --smode colormap. For example, --range 20 uses -20 to +20 percent. Values are rounded up to a multiple of 5, with seven colorbar labels that include 0 and use no decimal places.
--flag-chans [START,END]Use when --use-flags is enabled and the table FLAG channel axis is shorter than the data channel axis. This declares which original data channels the shorter FLAG array covers. Channels outside this window are treated as flagged. Example: --flag-chans "[0,3000]" means FLAG covers channels 0 through 2999.
--use-flagsApply the CASA FLAG mask. Default: disabled, so flags are ignored. If this option is used and the selected table has no FLAG column, GDP prints a warning and stops.
--smode MODE[,MODE...]Select stats products. Supported modes are gains, colormap, stats, ks, self-corr, all, and cross-corr. Modes may be comma or space separated. Legacy gain-colormap is accepted as an alias.
gainsSave selected gain/bandpass samples as a GDP gains NPZ product.
colormapSave the gains NPZ if needed and also save AntStat-style Real-1 and Imag percent colormap plots. Gain-mode plots use elapsed seconds from TIME and INTERVAL, show time-row numbers on the right-side axis of the right column, suppress duplicate left-side time labels there, include Delta t in the title, and use a 4:3 figure aspect ratio. Bandpass plots show nu in whole MHz on the left axis of left-column panels, preserve channel order from bottom upward, show channel numbers on the right axis of right-column panels, no duplicate left-axis labels on right-column panels, and show Delta nu in kHz with two decimal places in the title. Subplot mean/std/skew/kurtosis values are shown to one decimal place. The colorbar is symmetric from negative to positive saturation range and shows seven integer labels at multiples of 5 including 0.
statsCompute AntStat-style per-antenna mean, std, skew, kurtosis, median, MAD, min, and max statistics. This remains the default when no subtask is selected.
ksCompute AntStat-style per-antenna fitted-normal KS D-statistics.
self-corrCompute self structure-function correlation curves and save a long-format NPZ product. Antenna/stokes/component series with fewer than two finite unflagged samples are skipped and saved as NaN lag bins.
allRun all stats modes listed before all: gains, colormap, stats, ks, and self-corr.
cross-corrReserved placeholder for cross-correlation products. GDP logs the task but does not write a cross-corr product yet.
--output-npz PATHOutput NPZ path. Default: configured stats/npz runtime directory.
--output-gains-npz PATHOutput gains NPZ path. Default: configured gains/npz runtime directory.
--output-ks-npz PATHOutput KS NPZ path. Default: configured ks/npz runtime directory.
--output-self-corr-npz PATHOutput self-correlation NPZ path. Default: configured self-corr/npz runtime directory.
--output-cross-corr-npz PATHOutput cross-correlation NPZ path. Default: configured cross-corr/npz runtime directory.
--output-cross-corr-csv PATHReserved for future cross-correlation CSV output.
--output-colormap PATHOutput path for the optional colormap plot. Legacy --output-gain-colormap is accepted as an alias.
--plot-format {png,pdf,eps}Plot format for --smode colormap. Default: png. PNG files are written at 320 dpi.
--corr-threshold FLOATS2 threshold used for cross-correlation time extraction. Default: 0.7.
--corr-nbin INTStructure-function lag bin count. Default: 32.
--corr-bintype {log,lin}Structure-function lag binning. Default: log.
--corr-njack INTJackknife folds for structure-function errors. Default: 32.
--csvAlso write optional CSV products for selected subtasks that support CSV, including stats and cross-correlation.
--output-csv PATHWrite CSV to a specific path; implies --csv.

Subtasks and Logs

Before products are created, gdp-stats checks any requested --scan values against the selected gain or bandpass table. If a scan is absent, it prints a text error with the missing and available scans and stops. Channel options such as --bchan, --echan, -pchans, and --flag-chans are valid only in bandpass mode; in gain mode GDP prints a text error and stops. Each subtask prints a start/done message with elapsed time and writes the same messages to a timestamped log file under the configured logs runtime directory.

The <scan> field is scan1, scan2, etc. by default. With --combine-scans, the field is allscans when no scan list is supplied, or scan1-2/scan5 style when --scan is supplied.
